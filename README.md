# Taller 04: Interpolación y polinomios de Taylor

Autor: Nikolai Ortega

Código Python para aproximar ln(x) con polinomios de Taylor centrados en x0 = 1 y producir las dos gráficas requeridas.

## Ejecutar

```bash
python3 -m pip install numpy matplotlib
python3 taller04.py
```

Archivos generados:
- `grafica_1.png`: ln(x), P1, P2, P3 y P6 en [0.1,3].
- `grafica_2.png`: errores para x=1.5 y x=2.5, con la cota en x=1.5.
